## Resumo

Este estudo independente e não oficial documenta um inventário experimental SPDX 2.3, em nível de código-fonte, do conjunto público NASA core Flight System (cFS) v7.0.1. Identifica 25 componentes vinculados por Git e fixados em commits específicos, e relata correspondência exata dos identificadores completos de commit para os 25 componentes em comparação com o pacote oficial Version Description Document (VDD). Um inventário delimitado das árvores Git registra 4.341 entradas; as evidências complementares incluem 316 linhas de evidências de dependências e 28 linhas de evidências de licenças, sem transformar declarações em dependências de compilação confirmadas nem em conclusões de licenciamento para pacotes inteiros. A pesquisa sobre vulnerabilidades é documental e parcial, e o mapeamento de normas consiste em uma autoavaliação com lacunas registradas. O inventário não demonstra completude quanto a binários, implantação, execução, dependências transitivas ou vulnerabilidades, nem qualificação para voo ou certificação de segurança. A NASA não produziu, endossou, certificou nem aprovou esta pesquisa independente.

**Palavras-chave:** SBOM; SPDX 2.3; NASA cFS; proveniência Git; reconciliação VDD; pesquisa reproduzível; cadeia de suprimentos de software.
