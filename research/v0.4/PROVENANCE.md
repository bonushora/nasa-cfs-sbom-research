## Experimental lineage

- MT30: authenticated Lua package provenance and
  isolated prefix qualification.
- MT31: native EDS build and installation qualification.
- MT33: six SPDX inventories and static ELF evidence.
- MT35-R2: final R5-B semantic supplement, static CTest
  reconciliation and independent readback.

The full SHA-256 identities of the preserved source
manifests are recorded in PROVENANCE.json.

Public files are either byte-identical copies or
explicit derivatives. The derivation mapping records
both original and public file hashes.

Local path tokens such as `$BUILD`, `$INSTALL` and
`$LUA_PREFIX` denote experimental roots, not
instructions to access a public machine.

Original experimental evidence remains unchanged.
The historical v0.3 publication remains anchored to
its existing immutable Git commit.

The public package integrity manifest authenticates
the bytes of this package when its own SHA-256 is
obtained through a trusted channel. It is not a
digital signature or independent proof of all
experimental claims.
