# Pre-registered hypotheses

All hypotheses are NOT_TESTED.

## H1 — Verdict inflation

A specified pipeline that converts zero advisory
matches into an unrestricted secure verdict may
produce an unjustified conclusion after omission
of a relevant synthetic component.

Positive control: the complete inventory must
produce the planted synthetic advisory match.

If the positive control fails, the experiment
is invalid.

If the evaluator makes only a scoped no-match
statement, or blocks the broader verdict, the
proposed failure is not demonstrated for it.

A deliberately naive promotion policy demonstrates
a policy failure, not necessarily a scanner defect.

## H2 — Reconciliation

A witness with an independent scoped reference
detects a missing required entity, identity
mismatch or absent required dependency.

Prediction: discrepancy recorded and requested
broad conclusion blocked.

Falsification: a required mismatch or unresolved
identity is accepted as reconciled.

## H3 — Integrity versus completeness

A schema-valid SBOM with regenerated checksums can
omit a required reference component.

Prediction: schema and integrity PASS, scoped
coverage FAIL.

Invalid construction: schema/checksum failure or
failure to independently establish the missing
reference identity.

## H4 — Configuration awareness

An inventory of one configuration cannot support
another configuration without reconciliation
against the latter's required reference scope.

Prediction: controlled substitution detects
configuration or coverage mismatches.

Falsification: the required reference universe
is equivalent under the declared scope.

Invalid comparison: source, build, install or
runtime scope is silently mixed.

## H5 — Specificity

A valid scoped control must not be blocked merely
because an explicitly excluded component is absent.

Falsification: justified out-of-scope exclusions
or legitimate duplicate identities cause an
incorrect insufficiency verdict.

## Scientific discipline

Freeze scope, reference truth, evaluator version,
advisory snapshot and expected controls before
execution. Record negative and inconclusive results.
Do not treat an invalid control as a positive finding.
