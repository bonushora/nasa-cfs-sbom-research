## Pesquisa científica v0.2

Este repositório contém um inventário experimental e independente de SBOM SPDX 2.3 em nível de código-fonte do NASA core Flight System (cFS) v7.0.1. O estudo relata reconciliação exata de 25 de 25 identificadores Git de componentes com o pacote oficial VDD, além de um inventário delimitado das árvores Git e matrizes de evidências sobre dependências e licenças.

**Limites:** não representa um SBOM de compilação, binário, implantação ou execução; não estabelece completude de dependências transitivas, afetação por vulnerabilidades em nível de commit, qualificação para voo ou certificação de segurança. **A pesquisa não foi produzida, endossada, certificada nem aprovada pela NASA.**
